ILUSTRASI SVG LABORATORIUM GENETIC ADVENTURE - TEMA BIRU

File SVG di folder ini dipakai oleh delapan stasiun praktikum. Kamu dapat mengganti ilustrasi dengan SVG buatan sendiri tanpa mengubah JavaScript, asalkan nama file tetap sama:
- packaging.svg: perakitan kemasan DNA
- chromosome.svg: identifikasi kromosom
- gene-allele.svg: gen dan alel
- dna-pairing.svg: pasangan basa DNA
- transcription.svg: transkripsi DNA menjadi mRNA
- dna-rna.svg: klasifikasi DNA dan RNA
- monohybrid.svg: persilangan monohibrid
- dihybrid.svg: persilangan dihibrid

Panduan file pengganti:
1. Gunakan SVG mandiri dengan atribut viewBox.
2. Jangan memakai script, iframe, font eksternal, atau gambar dari URL internet.
3. Gunakan warna kontras dan latar transparan atau warna sangat terang.
4. Untuk diagram kromosom, sisakan ruang di tengah gambar karena marker A, B, dan C ditampilkan sebagai hotspot di atas ilustrasi.
5. Simpan file dengan nama yang persis sama agar otomatis terbaca.

Ilustrasi statis dapat diganti langsung. Bagian interaktif seperti slot drag-and-drop, dropdown, slider, dan tombol langkah tetap dibuat oleh aplikasi sehingga tidak hilang saat SVG diganti.


Catatan aksesibilitas: teks dan kontrol interaktif tetap disediakan oleh HTML aplikasi. SVG hanya menjadi ilustrasi pendukung, sehingga teks penting tidak boleh hanya ditanam di gambar.
